扩展知识 So / Such ... that ... 如此…以至于…

更新于:2024-01-24 08:03:23
such 和so 都可以用于表示程度，但 so 只能作副词和连词，such 则是形容词，因此 so 通常位于形容词、副词之前，而 such 只能位于名词之前。
so + adj./adv. + that… such + (a, an) n. + that…
  • The story is so interesting that(所以) I want to share it with you.
  • I am so tired that(所以) I want to sleep for an entire day.
  • The thieves ran away so quickly that I didn't have time to call the police.
  • .
  • It was so cold that no one went out.
  • I’ve never read such(如此) an interesting book.
  • It is such an interesting story that(所以) I want to share it with you. （尝试拆分成2句）
  • It is such a heavy box that I cannot carry it.
  • .
so ... that.... / such ... that ... 结果状语从句，是一个因果关系。一旦有名词, 就认为形容词修饰的是名词, 前面的词也修饰的是名词，如果名词是可数名词单数才要加a 和an, 反过来如果是可数名词单数, 前面一定要加 a 或 an 。
such 像这一类的 so + many, much, little, few
  • He often talks about such things.
  • You should not speak to such people.
  • He is such a lazy boy.
  • There is such a little bird that I can't see it.(little + 可数名词=“小”)
  • There is so little time left that we must hurry. (little + 不可数名词=“少许、一点”)
  • He is a boy so lazy.
如果有几个以上的形容词共同修饰一个名词的时候, 冠词放在第一位, 这句话中冠词不放在第一位, 说明 “a” 与 “boy” 有关系, “lazy” 从意思上与 “boy” 有关系, 但从强调点上与 “boy” 没关系, 它的强调点在 “lazy” 上。
