扩展知识 Must, Have (got) to and Need

更新于:2024-02-03 12:07:50

Must （必须，不得不）

must 用于表示推测
  • must + do 现在和将来的推测
  • must be doing 正在发生的事情的推测
  • must have done 对过去的推测
  • must have been doing 过去正在发生的事情的推测
一般疑问句
  • Must I set off now? 通常不用 mustn’t 回答
  • Yes, you must / have to. No, you needn’t.  回答 must/have to 或 needn’t
mustn't（不能、不准）表示绝对禁止，在说话人看来，根本没选择余地
  • You mustn’t use that bicycle.  “不必要”可用 needn’t
  • It’s broken. 

Need （需要）

needn’t 不必（情态） = don’t have to (实义)
  • You needn’t / don’t have to work such long hours.
  • need I...?(情态) / Do I need...? 实义动词
  • Need I go out? = Do I need to go out? 做为实义动词时连接其它动词后面加 to do
  • Need you leave so soon? need 用于疑问句时，问者往往希望得到否定的回答(肯定句用 must，have to，ought to 或 should)
  • Yes, you must 回答可以用 must/had to . / No, you needn’t . 否定形式的回答可以用 needn’t
  • Need you have told him about my plans?
  • Yes, I had to. / No, I needn’t have.
  • Need I type this letter again?
  • I must go to the dentist this moring. 表示必要时，must 的语气比need 要强

didn’t have to =  needn’t have done
  • He needn’t follow me .情态动词后面不能直接用名词做宾语
  • A doesn’t need B needn’t to C didn’t need to D needs.
  • You needn’t have told me that. I know it is. 情态动词 need 后接动词原形
  • I needn’t have gone to the office yesterday. (完成式)表示说话人让对方选择或允许对方可以不做某事的主观意图
  • I didn’t have to  / didn’t need to go to the office yesterday. 过去式
  • mustn't VS. needn't → You musn’t read it bed. It’s bad for your eyes.
need doing sth. 用主动表达被动含义
  • 这里 need 属于实义动词, 动词 ing 相当于名词来理解
  • 有时态和人称变化,否定式为: don’t need doing
  • need doing 表达被动含义, 如: Your shoes need washing. 你的鞋子需(被)洗了 Your hair needs cuting.
  • want doing 用主动表示被动含义(主语一定是物)
need to be done (主语：人、物)  The child need to be …

be bad for… 对…有害
  • Smoking is bad for your health. 抽烟有害你的健康
  • You mustn't make a noise. The children are asleep. 你不应吵闹, 孩子们都睡了
  • You needn't drive so quickly. We have plenty of time.你不必开得那么快, 我们有足够的时间
  • =You don't have to(haven't got to) drive so quickly. We have plenty of time.
  • You mustn't smoke in a theatre. It is forbidden. 你不应该在剧场里抽烟, 这是不允许的
  • You needn't come with us if you don't want to. 如果你不想去, 你不必和我们一道去
  • =You don't have to (haven't got to) come with us if you don't want to.
